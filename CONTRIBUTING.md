# Contributing

This project is maintained by one person on a sporadic schedule. Contributions are welcome, especially reproducible compatibility fixes and in-game ADS calibration data.

1. Open an issue describing the weapon and optic item IDs, Project Zomboid build, dependency versions, expected result, actual result, and steps to reproduce.
2. For a code change, create a branch and submit a focused pull request. Explain how you tested it in game and attach before-and-after screenshots for visual calibration.
3. Do not commit files from Project Zomboid, Gael Gun Store, or Project Viewpoint ADS, personal save files, or third-party assets without permission.
4. Keep the compatibility mod client-side and preserve its Build 42 directory structure.

Maintainer review may take time. An issue or pull request does not guarantee a release date.
